## 📦 How to use the data

```bash
# main dataset (AI tools)
curl -O https://raw.githubusercontent.com/AMPM-AIOPS-HQ/awesome-ai-tools-pricing/main/data/ai_tools_2026.json
curl -O https://raw.githubusercontent.com/AMPM-AIOPS-HQ/awesome-ai-tools-pricing/main/data/ai_tools_2026.csv

# sub-site datasets
curl -O https://raw.githubusercontent.com/AMPM-AIOPS-HQ/awesome-ai-tools-pricing/main/datasets/cards/cards_2026.json
curl -O https://raw.githubusercontent.com/AMPM-AIOPS-HQ/awesome-ai-tools-pricing/main/datasets/esim/esim_2026.csv
curl -O https://raw.githubusercontent.com/AMPM-AIOPS-HQ/awesome-ai-tools-pricing/main/datasets/index.json      # list of all datasets with counts and URLs
```

```python
import json, urllib.request
idx = json.load(urllib.request.urlopen("https://raw.githubusercontent.com/AMPM-AIOPS-HQ/awesome-ai-tools-pricing/main/datasets/index.json"))
for d in idx["datasets"]:
    print(d["dataset"], d["rows"], d["last_verified_max"], d["json"])
```
